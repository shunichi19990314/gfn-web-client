GeForce NOW にサインイン

NVIDIA ID のデバイスフロー認証を使用します。 パスワードはこのサーバーを一切通過しません。

公式Webクライアントからトークンをインポート(上級者向け)

QRもコード入力も使えない場合の最終手段です。
① 公式 play.geforcenow.com を開き、NVIDIA IDでログインする
② F12(開発者ツール)→「Application / ストレージ」→ Local Storage → https://play.geforcenow.com
③ eyJ で始まる長い値(JWT。idToken / accessToken 等のキー)をコピーする
④ 下に貼り付けて「インポート」を押す

⚠ このトークンはアカウント資格情報と同等の権限を持ちます。 自分で運用している、または信頼できるサーバー以外では絶対に使用しないでください。 インポートしたセッションは自動更新ができず、トークン失効時に再インポートが必要です。

非公式クライアントです。NVIDIA / GeForce NOW とは無関係であり、 NVIDIA の利用規約に抵触する可能性があります。自己責任でご利用ください。
